# Paper Reports

本目录用于存放论文结构、草稿、相关工作和复现性说明。

当前状态：

- `outline.md` 为细化后的论文设计文档，仍然只代表计划中的结构与证据边界。
- `contribution_list.md` 记录每项贡献的本地来源、所需证据和当前可用状态。
- `claim_evidence_matrix.md` 约束当前允许使用的论文措辞，避免把计划写成事实。

写作纪律：

- 不把 post-release analysis 描述成赛时盲测。
- 不把尚未完成的实验写成结论。
- 不长段转载 public prompt 原文，优先使用结构标签、短摘录和摘要。
- 如果某个 claim 仍缺少 corpus、taxonomy、screening 或 full eval 证据，必须在矩阵中标为 planned 或 unsupported。
